# 使い方

左のメニュー (左キーで開く) から **録画・ライブ・設定** へ行きます。キーの全部は [controls.md](controls.md)。
ブラウザの denpa と同じ決まり・同じタイミングにそろえてあります。
設定の画面は繋ぐ先とアプリの版 (と繋いだ denpa の版) だけで、画質・速さ・CM 飛ばし・字幕・音声は再生の画面の操作の列で替えます。

## ライブ

- 開くと**最後に観ていた局**が映る (初めてなら局の一覧の先頭)
- **左右で前・次の局**。本放送と同じものを流しているサブチャンネル (NHK総合2、Eテレ2・3 など) は飛ばす
  (番組表がまだ空なら全部を回る)。押すとすぐ行き先の局・番組が出て、**キーを離して 0.5 秒たってから替える**
  (続けて押せば途中の局ではチューナーを替えない)。替えると局・番組・番組の進みが数秒出る
- **数字キーで、その番号 (リモコン番号) の局へすぐ替える** (0 は 10、日本向けのリモコンの 11・12 も)。同じ番号の局が地上波と BS にあれば、いま観ている種別のほう
- 替えている間は**前の局の映像のまま**。1.5 秒たっても映らなければ読み込み中の印と「選局しています」(ストリームが届けば「映像を待っています」)、
  6 秒たっても映らなければ前の映像を暗くする
- **下キー・決定で下の端にメニュー**。上の段が**操作の列**、その下に**局の列**。上キーなら同じメニューを局の列のいまの局にフォーカスして開く。
  8 秒触らなければ閉じる
  - 操作の列: **画質** (H.264 / AV1 / MPEG-2 のうちこのテレビでデコードできるもの。すぐ替わり、テレビごとに覚える。既定は MPEG-2 をハードでデコードできれば MPEG-2、
    でなければ H.264)、**字幕**・**音声** (あれば)、**録画**
  - **録画**: いま観ている番組を denpa に予約する (始まっている番組は数秒で録りはじめる。二重には録らない)。
    録っている・録る予定ならボタンが「録画中」「予約済み」 (局の列の印と同じ呼び方)。録れないとき (チューナーの競合など)・番組表に無いときは1行出す
  - 局の列: **地上波・BS・CS (あれば SKY) が1列ずつ**縦に並ぶ。カードは番号・ロゴ・局名・いまの番組と、視聴中・録画中・予約済みの印。
    サブチャンネルは別の番組を流しているときだけ並ぶ
- **決定の長押し (情報キーも) で、いま放送中の番組の詳細**。番組名・局・時間・番組の進みと残り、ラベル (録画中・予約済み・ジャンル・映像・音声)、
  説明と放送の詳細 (`api/programs/<id>`。番組表から消えた番組では番組名と時間だけ)。ボタンは「録画」と「閉じる」。
  録っている・録る予定なら「録画」のボタンは出さず (印で分かる)、「閉じる」だけ
- 観ている局がスキャンのし直しなどで一覧から消えても、映しているものは止めない (通知だけ出す)
- **録画にチューナーを譲ったとき** (denpa のライブは録画にだけ譲る。ほかのチューナーが空いていても譲ることがある)。
  ブラウザの denpa のライブと同じ動き (denpa の docs/stream.md「録画に譲る」):
  - まず同じ局をリクエストし直す。denpa に使えるチューナーがあれば、観ているものは変わらない (前の映像のまま少し止まるだけ)
  - リクエストし直しても映らなかったときだけ、**譲った録画の追っかけ** (録れているところの少し手前から) に切り替え、
    下の端に「録画のため局を切り替えました: <番組名> (録画中の番組を再生しています)」を出しっぱなしにする
  - 決定でメニューを開くと **「ライブに戻る」** にフォーカスが移る (メニューは「ライブに戻る」と画質と局の列だけ。局の列や左右で別の局へも替えられる)。
    押すとリクエストし直しを試し、まだ録画がチューナーを塞いでいれば追っかけに戻って「録画が終わるまでライブは見られません (<終了時刻>)」
  - どの録画に譲ったかは denpa の通知 (`api/events` の `yielded`) で知る。通知に繋がっていなければ、いつもどおりリクエストし直し続ける
  - 同じチャンネルの録画ならチューナーを共有するので、譲らない (何も起きない)

## 録画

- 放送日ごとの見出しで新しい順に 3 列で並び、開くと**一番下 (いちばん古い録画)** にフォーカスが移る (古いものから片付けられるように)
- カードはポスターと番組名。途中まで観たものは観た割合のバー、まだ観ていないものは番組名の頭に小さな水色の点 (上の段の手引きにも書いてある)。
  局名は放送のまま (全角の英数字も半角に寄せず、放送の字で詰めて組む)
  **フォーカスした録画は上の段に大きく** (番組名・局・放送日時・長さ・観た割合・形式のラベル (AV1 / H.264 / 元のTS)・説明の頭の1行)、後ろにその画像をぼかして敷く
- 選ぶと**続きから**再生。観た位置は denpa に預けるので、ブラウザとも続きを分け合える。観て戻ると開いた録画にフォーカスを戻す
  (続きの位置が CM の中で CM 飛ばしがオンなら、CM の終わりから。そのときは「CM を飛ばしました」は出さない)
- 操作バーを開いている間の通知 (CM 飛ばしのオン・オフ・チャプター送りなど) は、操作バーのタイトルの2行目に出る (下の端に重ねない)
- 操作の列: 一時停止 / 再生、前へ・次へ (チャプター)、**速さ** (1 / 1.25 / 1.5 / 2 倍。音の高さはそのまま。ボタンは等速ならメーターの印だけ、速めている間は数字だけ)、**CM 飛ばし**、
  **字幕**・**音声** (あれば)、削除。速さと CM 飛ばしはテレビごとに覚える
- **CM 飛ばしは既定でオン**。ただし denpa がロゴで CM を判定できなかった録画 (`cmReliable` が false) はオフで始まる (オンにしてもその録画だけ)。
  区切りは denpa が見つけた CM の位置 (エンコード済みのファイルはチャプター、エンコード前の録画は denpa の `chapters`)。CM を切ってエンコードした録画や、
  CM を見つけられなかった録画には無い
- 何で観るかは denpa に聞いて、テレビがデコードできるものから選ぶ。エンコード前・エンコードに失敗した録画は、denpa に流してもらう
  (MPEG-2 のデコーダが無いテレビでは denpa が H.264 に変換する。[playback.md](playback.md#録画))
- **長押しで詳細**: 番組名・局・放送日時・長さ・観た位置・形式 (と音声) のラベル、説明と放送の詳細。
  ボタンは「続きから再生」(続きが無ければ「再生」)・「最初から」(続きがあるとき)・「削除」・「閉じる」。
  本文は説明と番組内容をまとめた読みもの → 出演者 → 制作・原作・音楽など → おしらせの順で、下キーで入って読み進める。
  ライブ・再生中の詳細も同じ並びで、「閉じる」はどれも右の端 (再生中は「削除」・「閉じる」で、開くと「閉じる」にフォーカスが移る)
- denpa の通知で読み直そうとして読めなかったら、いまの一覧は出したまま、上の段の隅に「denpa に繋がっていません」。
  録画が1つも無いときは「ライブへ」のボタン
- **削除は2回押し**: 1回目で「もう一度押すと削除」、4 秒以内にもう一度で消す。再生中に消すと一覧の隣の録画に戻る
- **最後まで観たら**位置を預け (次は頭から)、「最後まで観ました」と **一覧へ戻る** / **削除** (削除にフォーカス。2回押し)。勝手には戻らない
- 録画中の録画は「● 録画中」が付き、選ぶと**追っかけ再生**
- 開いている間は denpa の通知 (`api/events`) を受け、録画が増えた・エンコードが終わった・消えたら一覧を、局・番組表・予約・録画が変わったらライブの局 (録画の印) を読み直す。
  エンコード中の録画は「エンコード中 42%」
- 途中で閉じた録画はテレビのホームの「続きを視聴」に出る (Android 8.0 以降。観終えた・消したものは消え、ほかの端末で観た位置にも合わせる。
  ホームで外したものは、もう一度観るまで出さない)

## 追っかけ再生

録画中の録画は `api/recordings/<id>/chase` で観ます。続きの位置があればそこから (無ければ頭から)。キーは録画の再生と同じ。

- 画質はライブと同じ設定 (MPEG-2 をハードでデコードできれば元の TS、でなければ H.264)。操作の列で替えられる
- 止めたまま操作バーが閉じたら、録画と同じく「一時停止」と位置のバーが出たまま (決定で動かす)
- 流しっぱなしの1本なので、**位置・速さを変えると今の位置からリクエストし直す** (続けて押したぶんはまとめる)。長く止めてから動かしたときも同じ。
  シークバーの長さは録れたところまで
- **最新の近くまで来ても飛ばず、ライブのように観つづける**。速くして追いかけていたら、追いついたところで等速に戻す。「最新」で最新の少し手前へ
- 録り終えて最後まで来たら「最後まで観ました」
- **観ている間にエンコードが終わったら、ファイルの再生へ移る** (観ていた位置から。「エンコードが終わったので、ファイルで再生します」)。
  録り終えたか (`state`) を聞き、エンコード済みのファイルをこのテレビで再生できるなら (`playback`) 移る。「エンコードしない」設定の録画 (元の TS だけ) は移らない。
  止めている・操作バーや詳細を開いている間は待ち、閉じたら・動かしたら移る。位置は denpa がエンコード済みのファイルの時刻に直す
  (CM を切ってエンコードした録画でも同じ場面から)
- H.264 / AV1 は、番組が替わって映像・音声・字幕の並びが変わったところで denpa が閉じる。届いたぶんを観終えてから、観ていた位置からリクエストし直す
- denpa が H.264 / AV1 に変換できなかった (何も送らずに閉じた) ときは何度かリクエストし直し、続いたら「映像を送らずに閉じました」。少し待つか、画質を替える
- denpa の変換の枠が埋まっている (同時に変換する本数の上限。denpa の設定の「GPU」) と、H.264 / AV1 は断られる。
  何度かだけリクエストし直し、だめなら「サーバが混んでいます」。MPEG-2 をデコードできる端末なら「画質を MPEG-2 にしてください」と添える (MPEG-2 は変換しない)
- 録画が無い・まだ何も録れていない (録りはじめた直後) と「録画が無いか、まだ何も録れていません」
- 録画中は消せない

## 字幕と音声

- **字幕**は操作の列の「字幕 オン / オフ」で切り替え (テレビごとに覚える。既定はオン)。字幕の無い映像ではボタンが出ない
- 放送の字幕 (ARIB) は denpa がデコードして**置き場所・大きさ・色まで決めた文字の配置**を受け取り、アプリが文字として描く
  (ブラウザの denpa と同じ描き方。縁取り・囲み・下線・点滅・ルビ・外字も)
  - 元の TS (ライブ・追っかけ・エンコード前の録画) は `api/services/<id>/captions`・`api/recordings/<id>/captions` で受け取り、放送の PTS に合わせて重ねる
  - エンコード済みの録画は `api/recordings/<id>/captions.json` をまるごと受け取る
- 字幕と、放送から来た字 (番組名・説明・局名) は **Denpa Font** (BIZ UDゴシックを丸めたもの。ブラウザの denpa と同じ字) で描く。
  番組表の記号 (外字) もテレビと同じく白黒で出る。アプリのボタンや見出しは端末の字
- 操作の列・メニュー・通知を下に出している間は、字幕をその上へ持ち上げる
- **音声**は2本以上あるときだけボタンが出て、押すたびに次へ。名前は denpa が書いた放送の名前 (「解説ステレオ」など)、
  無ければ「音声 2 (日本語)」。名前の付いた音声を選ぶと覚えて、次に同じ名前があればそれで始める
- 変換したライブ・追っかけ (H.264 / AV1) は音声が1本なので、選ぶと denpa に再エンコードしてもらう (`?audio=<id>`。その画面の間だけ)
- **二か国語 (デュアルモノ)** は「主音声」「副音声」「主+副」(既定は主音声。テレビごとに覚える)。
  元の TS はアプリが選んだ側を両耳へ配り、変換したライブ・追っかけは denpa にリクエストする。エンコード済みの録画は denpa が2本に分けてある

## リンクで開く

`denpa://` のリンクで局や録画を直に開けます (Home Assistant の自動化や adb から)。

| リンク | 開くもの |
| --- | --- |
| `denpa://live` | ライブ (最後に観ていた局) |
| `denpa://live/<局>` | その局のライブ。`<局>` は局の id (`GET /api/services` の `id`)・名前・番号 |
| `denpa://recordings` | 録画の一覧 |
| `denpa://recording/<id>` | その録画を観る (続きから。録画中なら追っかけ再生) |

- 局の名前は、そのまま → 全角・半角・大文字・小文字・空白を揃えて → 番号 (リモコン番号、BS/CS は3桁) → 名前の頭、の順に探す。
  「ＮＨＫ総合１・東京」は `NHK総合`・`1` でも当たる。% で符号化してもよい
- 見つからなければライブ・録画の一覧をふつうに開いて1行知らせる
- 観ている途中に来たら再生の画面を入れ替える (戻るで、ライブならメニュー、録画なら一覧へ)
- まだ denpa に繋いでいなければ、リンクは捨てて繋ぐ画面のまま

Home Assistant の [Android TV Remote](https://www.home-assistant.io/integrations/androidtv_remote/) から:

```yaml
action: media_player.play_media
target: { entity_id: media_player.android_tv }
data: { media_content_type: url, media_content_id: denpa://live/NHK総合 }
```

adb から:

```sh
adb shell am start -a android.intent.action.VIEW -d denpa://recording/12
```

## できないこと

- **データ放送**は出ない。ブラウザの denpa を使う
- 番組表・予約の一覧・ルールはまだ無い (録れるのは、ライブで観ている番組の「録画」だけ)
