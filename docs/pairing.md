# denpa に繋ぐ

手順の短い版は [README](../README.md#denpa-に繋ぐ)。

1. 初めて開くと、繋ぐ画面に QR コードが出る。スマホをテレビと同じ Wi-Fi に繋いで読む (テレビの中の小さなページが開く)
2. ブラウザで denpa を開いている URL を入れて送る (例: `http://192.168.1.10:3000/`、`https://denpa.example.jp/`)。
   ポートを省くと 80 のあと 3000 も試し、つながったほうを使う
3. **家の LAN の denpa** (テレビが denpa の `TRUSTED_NETWORKS` に入っている) なら、スマホに「設定しました」と出て、テレビは録画の画面に進む
4. **ログインが要る denpa** (OIDC でログインする構成。テレビが `TRUSTED_NETWORKS` の外) なら、スマホが denpa の画面に移る。ログインすると denpa がこのテレビを登録し、
   テレビは自動で進む (QR で開いたページがこのテレビと結び付いていて、コードは URL で denpa に届くので、打つ・見比べるは要らない)

リモコンで URL を打つこともできます (ログインが要る denpa なら、テレビに出る QR / URL を別の端末で開いてログイン)。
欄の `http://` のあとに URL をまるごと打っても (`http://https://…`) そのまま使えます。

## 要る denpa の版

**denpa v1.55.0 以上** (録画の観方と流し方 `playback`・`stream` がこの版から)。繋いだとき (繋ぎ直すたびにも) `api/health` で版を確かめ、
古ければ録画の一覧の頭と設定に「denpa v1.55.0 以上が必要です (いまは v1.54.0)」と出します。
止めはしません (無い API のところが出ないだけ)。手元でビルドした denpa (`dev`) は確かめません。

## 安全のために

- **繋ぐのは同じ世帯のテレビだけ。** denpa は自分の世帯の中で私的に観るためのものです
  ([README](../README.md#使ってよい範囲))
- **テレビの中のページは、繋ぐ画面を開いている間だけ**待ち受ける。URL には推測できない文字列が入っていて、
  QR を見ていない同じ LAN の誰かは開けない。ページは http (LAN の中だけ) で、受け取るのは denpa の URL だけ
  (パスワードは扱わない。ログインは denpa の画面でする)
- 登録で受け取るアクセストークンは、アプリの領域 (他のアプリから読めない) に置く。テレビを手放すときは
  「設定」→「接続先」のボタン (押すと登録を解除) で無効にする (denpa の画面からも外せる)
- アクセストークンが効かなくなる (外された・期限切れ) と、繋ぐ画面に戻る
