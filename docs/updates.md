# アプリの中のアップデート

2回目からはアプリの中で上げられます (パソコンは要りません)。最初に入れるのは [install.md](install.md)。

アプリを開くと (12 時間に1回まで) GitHub のリリース (プレリリースを含む) を確かめ、新しい版があれば裏で APK を落として
`SHA256SUMS` と照らします (一致しない・`SHA256SUMS` が無いときは入れない)。準備ができると録画の一覧の上に「アップデート (v0.4.0)」が出ます。
上キーで選んで押すとテレビの確認画面が開き、入れ終わるとアプリが閉じるので開き直してください。

- 初回は「不明なアプリのインストール」の許可画面が開く。denpa を許可して戻ると確認画面に進む
  (許可画面にいる間にアプリが閉じても、30 分以内に開き直せば続きから)。
  許可が見えないテレビもあるので、一度許可画面を開いたあとはそのまま試す (許可されていなければテレビが知らせ、そこから設定を開ける)。
  設定で「許可」なのに進まないときは、一度オフにしてからオンにする (BRAVIA で起きる)
- Play プロテクトの「ブロックされました」が出たら、「OK」ではなく「インストールする」(INSTALL ANYWAY)
- 確認画面が出ないまま 30 秒たつと、押し直せる表示に変わる
- 一度アプリの中で上げると、次からは確認画面なしで入ることがある (Android 12 以降)
- 裏で落とせなかったときも「アップデート (v0.4.0)」が出て、押すと落とすところから (「ダウンロード中 42%」)
- 落とした APK は版ごとに cache に残し、開き直しても照らし直して使い回す。古い版のものは消す
- 設定の「バージョン」の札を押すとすぐ確かめる (新しい版があれば、同じ札で入れる)
- 開いたときの確認は、GitHub に届かなくても何も出さない。開発版 (`0.0.0-dev`) では確かめない
- `-debug` の付いたリリースは署名が違うので対象外

手元で偽のリリースから試す方法は [release.md](release.md#アプリの中のアップデートを確かめる)。
