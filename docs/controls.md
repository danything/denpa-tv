# リモコン

十字キーと決定・戻るだけで全部に届きます (Google TV・Fire TV のリモコンには Menu キーもチャンネル送りも無いことが多いので)。
Menu キーやチャンネル送りがあれば、ショートカットとして効きます。割り当ては `data/Remote.kt`。

| キー | ライブ | 録画の再生・追っかけ再生 |
| --- | --- | --- |
| 左 / 右 | 前 / 次の局 (サブチャンネルは飛ばす。離してから替える) | 10 秒戻す / 送る |
| 下 | メニュー (操作の列にフォーカス) | シークバーと操作の列 |
| 上 | メニュー (局の列の、いま映している局にフォーカス) | 操作の列 |
| 決定 | メニュー | 止める・動かす (止めると操作の列が「再生」にフォーカスして開く) |
| 決定の長押し | 番組の詳細 (そこから録画も) | 番組の詳細 |
| Menu | メニュー | 操作の列 |
| 戻る | 開いているものを閉じる。何も無ければいちばん上のメニューへ (「ライブ」にフォーカス) | 開いているものを閉じる。何も無ければ一覧へ (開いた録画にフォーカス) |
| CH+ / CH- | 次 / 前の局 | — |
| 次へ / 前へ | — | チャプター送り |
| 早送り / 巻き戻し・再生 / 一時停止 | — | 左右・決定と同じ |
| 緑 | — | 速さを1段送る |
| 情報 | 番組の詳細 | 番組の詳細 |
| 番組表 | 番組表 (いま映している局のいまの番組にフォーカス) | — |
| 数字 (0〜9・11・12) | その番号 (リモコン番号) の局へすぐ替える。0 は 10。同じ番号の局が何局かあれば、いま観ている種別 (地上波・BS) のほう | — |

ライブのメニューの中:

| キー | 操作の列 (画質・字幕・音声・録画) | 局の列 (地上波・BS・CS) |
| --- | --- | --- |
| 上 / 下 | 上: 閉じて映像に戻る。下: 局の列へ (いまの局にフォーカス) | 前 / 次の種別の列。いちばん上の列から上で操作の列へ |
| 左 / 右 | ボタンを選ぶ | 局を選ぶ |
| 決定 | 押す | その局に替える (メニューは閉じる) |
| 戻る | 閉じる | 閉じる |

録画・追っかけの操作バーの中は、上下で操作の列とシークバーを行き来し、シークバーでもう一度上を押すと閉じます。

番組表 (表は全体で1つのフォーカスで、キーを全部ここで受ける。持つのは列・番組・基準の時刻):

| キー | 番組表 |
| --- | --- |
| 上 / 下 | 同じ局の前 / 次の番組。基準の時刻を、移った先の番組の始まりに替える。最初の番組で上を押すと上の段 (種別・日付・時刻) へ |
| 左 / 右 | 隣の局の、基準の時刻に流れている番組。基準の時刻は替えない。左の端で左を押すと左のメニュー |
| 決定 | 番組の詳細 (予約・予約取消・視聴・再生) |
| 戻る | 上の段へ |
| CH+ / CH- | 6 局ずつ右 / 左へ送る |
| 早送り / 巻き戻し | 3 時間ずつ先 / 前へ送る |
| 録画 | フォーカスしている番組を予約する。予約できない番組 (予約済み・終わった・コピー禁止) は詳細を開く |
| 数字 (0〜9・11・12) | その番号 (リモコン番号) の局へ。ライブと同じ決め方 (いまの種別を先に) |

上の段では、左右でボタンを選び、決定でその種別・日付・時刻へ表を動かします (フォーカスは上の段のまま)。下キーで表へ戻ります。

## 決めたこと

- **ライブは左右で局替え、下でメニュー**。YouTube・Prime Video・ABEMA など、テレビのアプリの多くは下キーでメニューを開くので。
  局と番組の進みは替えるたびに数秒出るので、メニューを開かなくても分かる。上キーは同じメニューを局の列から開く (一覧から局を選ぶショートカット)
- **録画は下キーでシークバー** (多くの Android TV のアプリと同じ)。止める・動かすは決定1回、10 秒の戻し・送りは左右1回、
  CM は自動で飛ばすので、ふだんは操作バーを開かずに済む
- 操作バーは下の端に小さく出し (下から薄く暗くするだけ)、5 秒触らなければ消える (止めているときも。ライブのメニューは 8 秒)。
  止めている間は、操作バーが閉じても位置の進行バー (録画は CM の印も) が出たまま (録画・追っかけ)
- 止めると操作の列が開いて「再生」にフォーカスが移るので、決定でそのまま動かせる。動かすと操作バーは閉じる
- **決定の長押し**は、キーの繰り返し (長押しの印) か、**押したまま 0.7 秒**で決まる (押した・離したしか送らないリモコンでも長押しになる)。
  情報キーの無いリモコンが多いので、詳細はこれで開く。長押しを離しても決定にはならず、開いた詳細は決定を押し直すまで受けない
- いちばん上の段 (ライブは操作の列、録画・追っかけはシークバー) で上を押すと閉じる。閉じるのは**その段にフォーカスが移ってから押しはじめた上キー**だけで、
  下の段から押し続けて上がってきたときは止まる (勢いで閉じてまた開く、とならないように)
- 操作バーを開いている間は、下の端の1行の通知を出さず、操作バーのタイトルの2行目に添える (重ならないように。操作バーの中で押した CM 飛ばし・画質の返事もそこに出る)。
  操作バーを開くと、開く前の通知 (開いてすぐの番組名など) は消す
- 続きから開いて、続きの位置が CM の中なら、飛んでも「CM を飛ばしました」は出さない (「続きから」だけ。ブラウザの denpa と同じ)
- **数字キーでワンタッチ選局** (テレビのリモコンと同じく局のリモコン番号で。テンキーも)。局の切り替えは CH± と左右のまま
- フォーカスしていたボタンが消えても (追っかけの「最新」に追いついたなど)、フォーカスは操作バーの中に戻す。戻るキーは「閉じる・戻る」だけに使う
- 左のメニューは戻るでも閉じる
- **番組表は表全体を1つのフォーカスにする**。マスごとにフォーカスを持たせると、フォーカスの移る先を Compose が近さで選び、短い番組と長い番組が並ぶ所で
  隣の局のどの番組へ移るかが揃わない。表が列・番組・基準の時刻を持ち、左右では基準の時刻に流れている番組へ移すので、左右に行き来しても元の時刻に戻る。
  作るのは見えているマスだけ (`LazyLayout`)
- **ライブから番組表へは、詳細の「番組表」と番組表キー**。操作の列は画質 (デコードできる形式の数だけ)・字幕・実況・コメントの一覧・音声・録画で1行が埋まっていて、
  足すと収まらない端末が出る。詳細のボタンは「録画」と「閉じる」だけで、いまの番組から先の番組を見に行く流れにも合う。
  番組表キーのあるリモコン (日本向けのテレビのリモコンなど) なら1回で開く
- **番組表の録画キーは予約だけをする**。予約済みの番組で押しても取り消さず、詳細を開く (押し間違いで予約を消さない。取り消すときは「予約取消」を選ぶ)
