# リモコン

十字キーと決定・戻るだけで全部に届きます (Google TV・Fire TV のリモコンには Menu キーもチャンネル送りも無いことが多いので)。
Menu キーやチャンネル送りがあれば、近道として効きます。割り当ては `data/Remote.kt`。

| キー | ライブ | 録画の再生・追っかけ再生 |
| --- | --- | --- |
| 左 / 右 | 前 / 次の局 (サブチャンネルは飛ばす。離してから替える) | 10 秒戻す / 送る |
| 下 | メニュー (操作の列に合う) | シークバーと操作の列 |
| 上 | メニュー (局の列の、いま映している局に合う) | 操作の列 |
| 決定 | メニュー | 止める・動かす (止めると操作の列が「再生」に合って開く) |
| 決定の長押し | 番組の詳しく (そこから録画も) | 番組の詳しく |
| Menu | メニュー | 操作の列 |
| 戻る | 開いているものを閉じる。何も無ければいちばん上のメニューへ (「ライブ」に合う) | 開いているものを閉じる。何も無ければ一覧へ (開いた録画に合う) |
| CH+ / CH- | 次 / 前の局 | — |
| 次へ / 前へ | — | チャプター送り |
| 早送り / 巻き戻し・再生 / 一時停止 | — | 左右・決定と同じ |
| 緑 | — | 速さを1段送る |
| 情報 | 番組の詳しく | — |

ライブのメニューの中:

| キー | 操作の列 (画質・字幕・音声・録画) | 局の列 (地上波・BS・CS・SKY) |
| --- | --- | --- |
| 上 / 下 | 上: 閉じて映像に戻る。下: 局の列へ (いまの局に合う) | 前 / 次の種別の列。いちばん上の列から上で操作の列へ |
| 左 / 右 | 札を選ぶ | 局を選ぶ |
| 決定 | 押す | その局に替える (メニューは閉じる) |
| 戻る | 閉じる | 閉じる |

録画・追っかけの帯の中は、上下で操作の列とシークバーを行き来し、シークバーでもう一度上を押すと閉じます。

## 決めたこと

- **ライブは左右で局替え、下でメニュー**。YouTube・Prime Video・ABEMA など、テレビのアプリの多くは下キーでメニューを開くので。
  局と番組の進みは替えるたびに数秒出るので、メニューを開かなくても分かる。上キーは同じメニューを局の列から開く (一覧から局を選ぶ近道)
- **録画は下キーでシークバー** (多くの Android TV のアプリと同じ)。止める・動かすは決定1回、10 秒の戻し・送りは左右1回、
  CM は自動で飛ばすので、ふだんは帯を開かずに済む
- 帯は下の端に小さく出し (下から薄く暗くするだけ)、5 秒触らなければ消える (止めているときも。ライブのメニューは 8 秒)。
  録画は帯が閉じても、位置と CM の印のついた帯が出たまま
- 止めると操作の列が開いて「再生」に合うので、決定でそのまま動かせる。動かすと帯は閉じる
- **決定の長押し**は、キーの繰り返し (長押しの印) か、**押したまま 0.7 秒**で決まる (押した・離したしか送らないリモコンでも長押しになる)。
  情報キーの無いリモコンが多いので、詳しくはこれで開く。長押しを離しても決定にはならず、開いた詳しくは決定を押し直すまで受けない
- いちばん上の段 (ライブは操作の列、録画・追っかけはシークバー) で上を押すと閉じる。閉じるのは**その段に合ってから押しはじめた上キー**だけで、
  下の段から押し続けて上がってきたときは止まる (勢いで閉じてまた開く、とならないように)
- 合わせていた札が消えても (追っかけの「最新」に追いついたなど)、合いは帯の中に戻す。戻るキーは「閉じる・戻る」だけに使う
- 左のメニューは戻るでも閉じる
